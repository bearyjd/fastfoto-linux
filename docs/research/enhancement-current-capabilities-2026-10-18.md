## Integration points and constraints

- Photo enhancement contract: `Enhancer = Callable[[np.ndarray, int], np.ndarray]`, immutable input; ordered tuple in `ProcessSettings` (`pipeline/process.py:40`, `:50`). `_prepare` orients first, then enhancers; any optional failure forfeits `_a` and retains original (`:343`). GUI/CLI currently order restore then red-eye (`gui/form.py:253`, `cli/options.py:180`); evaluate raw-eye detection versus post-restore detection before changing pipeline order.
- `find_red_eyes` already separates candidate detection (`EyeFix` ROI/mask) from `apply_fixes` (`enhance/redeye.py:71`, `:243`, `:284`). Natural seam for confidence, per-eye preview/acceptance and manual seed correction without replacing file output machinery. Public enhancer signature currently returns pixels only, so provenance/quality decisions need a deliberate result/sidecar interface.
- Shared face detector is cached and locked (`enhance/faces.py:1`); avoid independent competing models until benchmark demonstrates need. Vendored YuNet model is MIT; checked hash and offline runtime already established (`models/README.md:3`).
- Documents analyze/trim/assess/encode one sheet at a time (`documents/analyse.py:1`, `:35`, `:91`), then write/OCR/publish (`documents/build.py:1`). Add content classification after trim and before encode; preserve full-color originals for review/reclassification. `ANALYSIS_VERSION=1` (`analyse.py:31`) needs attention when persisted verdict/analysis meaning changes.
- True per-page Auto requires a distinct request setting, classification with conservative abstention, a stored chosen mode/reason, an override in page edits/review, and encode handling. Current `LoadedPage.kind` must remain a source-format description, not be overloaded with inferred content type.
- Fixing holes/creases/streaks in visible pixels is new enhancement work. Do not relabel current decision heuristics as implemented restoration.
- Runtime: Python>=3.13; NumPy>=2.1, OpenCV-headless>=5.0, Pillow>=11, img2pdf>=0.6.3, pikepdf>=10.17 (`pyproject.toml:10`). Optional OCRmyPDF>=17.13; external Tesseract (`:30`). Native GUI uses distribution PySide6/Kirigami, intentionally absent from pip deps (`:25`). No SciPy, scikit-image, PyTorch or ONNX Runtime dependency. GPL-3.0-or-later app; model MIT (`pyproject.toml:10`, `models/README.md:6`).
